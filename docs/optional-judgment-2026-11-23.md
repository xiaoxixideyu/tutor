# 可选判断服务验收记录

已增加“模型设置 → 判断模型（可选）”。默认完全使用大模型；也可选择 TypeSafe / Jev 辅助判断，独立设置服务地址、模型、密钥、置信度和等待上限。“核验大模型”可指定同一渠道中的其他模型，留空沿用主模型。网页明确关闭优先于环境变量启用，修改在下一教学回合生效。

快速判断当前处理画像原话依据与内容范围预检。可靠的画像判断可直接采用，明确越界可以提前拒绝；普通内容即使通过快速范围检查，也保留完整的大模型审核、盲解、数值复算和代码执行。教学策略、内容生成、主观题反馈和目标验收逻辑继续使用现有能力。

置信度及所选结论概率低于阈值、显式不确定、响应不合法、超时和上下文过大均回退大模型。预算用尽、用户暂停及共享队列存储故障不会通过回退绕过限制。回退路径和判断来源保存在审查记录中，缓存包含判断策略、阈值、检查契约及核验模型来源。

“测试快速判断连接”只发送固定样例，不发送课程记录，不保存或启用设置；每次尝试仍计入全局请求及用量。密钥单独保存在本机，不回显，不与主模型密钥混用，换址不沿用旧密钥。

## 中转接口扩展

补充“基础地址 / 完整请求地址”与“Choice / Noul”选项。完整地址原样发送，保留末尾斜杠和普通路由查询参数，不补全 /systemone。示例配置：urlMode=endpoint，baseUrl=https://emrank.tech/v1/decisions，questionType=noul，model=commandcode/jev-1.14.0。

Noul 保留服务返回的真实是/否概率，不制造置信度字段。中间概率或无效响应回退大模型。请求地址表示方式切换可沿用同一服务的密钥，更换实际服务地址仍需新密钥。
