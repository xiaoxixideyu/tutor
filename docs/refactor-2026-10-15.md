## 目标与结果

以功能结果为导向，去掉 DeepSeek Harness（dsh）基座，把「常驻 serve + 每流程 headless 子进程」收敛为单进程：

- `npm run agent -- serve` 是唯一进程；每条教学流程在进程内作为 async 任务运行（内存输入队列、停止＝信号中止 + 8s 超时释放）。
- HTTP/SSE 协议、页面、课程状态格式、会话日志事件名全部不变；`audit`/`fidelity` 零改动。
- 移除 `@deepseek-ai/dsh`（连带 410 个传递包）与 `src/plugin/`、`config/{settings,cordis.patch,search.patch}.yml`、DSH_HOME/模板渲染/子进程桥接。
- 教研搜索改用官方 `@modelcontextprotocol/sdk`（streamable-http）。

新增模块：`src/runtime/`（流式客户端、工具循环、会话日志、限流/退避/看门狗）、`src/flows/`（八个流程 + 内容审查网的纯函数编排）。
