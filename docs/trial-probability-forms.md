# 骰子概率独立测量题册

观察者每次只提供对应的一组题。各组限 8 分钟，不查资料、不使用模型。每题都指一次掷一枚公平六面骰子，六个结果等可能。写出列举或计算理由；分数不要求约分。不会可留空。

## 前测

1. 列出样本空间，以及点数为偶数的结果和概率。
2. 点数小于 3 的结果有哪些？概率是多少？
3. “点数是 6”的补集包含哪些结果？补集概率是多少？
4. 有人说：“奇数是一个事件，所以掷出奇数的概率是 1/6。”是否正确？说明理由并给出概率。

## 课后测

1. 点数大于 4 的结果有哪些？概率是多少？
2. “点数小于 2”与“点数不大于 2”分别有哪些结果、各是多少概率？
3. 事件 A 包含 `{2,4,6}`。列出 A 的补集，用 `1-P(A)` 计算补集概率。
4. 有人将三个互不重叠且覆盖全部结果的事件概率记为 `1/3、1/2、1/3`，并说它们合计为 1。这个记录是否可能正确？算出总和并说明。

## 次日测

1. 点数为奇数的结果有哪些？概率是多少？
2. “点数大于 5”与“点数不小于 5”分别有哪些结果、各是多少概率？
3. 事件 A 包含 `{1,2}`。列出 A 的补集，用 `1-P(A)` 计算补集概率。
4. 某事件 A 含两个基本结果。有人把 A 的补集概率也写成 `2/6`。是否正确？列出计算并解释。

## 一周测

1. 事件 A 包含 `{1,4,5}`，概率是多少？说明计数依据。
2. 点数不大于 4 的结果有哪些？概率是多少？点数 4 是否应计入？
3. 事件 A 包含 `{2,3,5}`。列出 A 的补集，用 `1-P(A)` 计算补集概率。
4. 事件 A 为 `{1,2,3}`，B 为 `{3,4,5,6}`。B 是 A 的补集吗？指出原因并写出真正的补集。
