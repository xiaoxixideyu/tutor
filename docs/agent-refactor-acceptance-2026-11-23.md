# 教学 agent 重构验收记录

日期：2026-11-23；版本：0.2.0；数据格式：V2。

本次已完成业务核心、运行时、CLI、网页与数据协议的工程重构。教学策略由单个 TutorAgent 根据目标、原话和学习证据选择；程序负责可验证的事实、受限执行、内容质量、预算与可靠提交。旧固定流程、YAML 课程入口、RPC 和文本驱动的网页协议已移除。

按用户授权，开发前已清理历史课程、会话、运行记录和审查数据；保留 .env 与 data/model-config.json 中的连接配置。真实模型工程验收保存在 data/evals/ 的独立目录，正常课程列表保持空白。个人数据和凭据不进入 Git。

## 完成范围

| 方面 | 最终行为 |
| --- | --- |
| 教学决策 | agent 可选择先讲解、先诊断、直接独立任务、继续当前活动、补救、复习或结束；入口命令表达用户意图 |
| 课程设计 | 按目标、期限和时间逐步形成近期技能与量规，保留跨单元前置；目标变更作为具体提案等待用户接受 |
| 画像与能力 | 自述、假设、作答证据、能力评定、记忆与活动进度分开；画像引用学员原话，假设验证需要新证据 |
| 验收规则 | 关键标准失败不能被其他分数抵消；提示后答案和重复题不能提供新的独立证据；目标完成另需整体范围核对 |
| 内容质量 | 独立检查范围与正确性，客观题盲解、数值复算、参考代码执行；错误稿实际修复后重审，禁止原样反复抽取通过 |
| 数据提交 | 不可变资产加原子状态快照；版本与输入哈希保护回执；作答在评分前保存，草稿另行持久化 |
| 多入口与恢复 | 跨进程运行互斥独立于短写锁；查询不会误暂停另一入口；死亡执行者可恢复，原始答案不变且只计分一次 |
| 交互 | CLI 和网页共用应用服务；类型化 SSE 按游标恢复，并同步其他入口的提交；失败恢复控件，多行草稿刷新可恢复 |
| 实践执行 | macOS 沙箱限制文件、网络和资源；支持 JavaScript、Python、Go WASI；缺少隔离适配器时使用开放任务 |
| 成本和等待 | 全部生成、审查、判分、重试与日程调用进入用量账；工具执行不消耗主模型的生成等待时限，但受整体任务时限约束 |

默认每回合最多 6 个业务动作、16 次模型请求；学习假设和多个技能判断可在一步中原子提交，保留动作额度用于教学与内容修复。默认估算预算为每回合 ¥2、每天 ¥10，并有每天 100 次请求上限；这些均可配置，估算值不等于实际账单。

## 真实模型场景

以下是隔离的工程模拟场景，输入背景和作答由开发者设定，不是学员学习实验。次数与费用为相应验收目录的累计记录，包含失败和恢复；费用单位为人民币元，使用 config/cost.yaml 的估算费率，未知用量仍计入请求数。

| 场景 | 实际结果 | 累计请求 / 估算费用 |
| --- | --- | --- |
| 零基础、只学 0–10 加法、每天 10 分钟 | 选择圆点合并诊断；首题答 5 后继续零加数情形，没有凭单题宣布掌握 | 7 / 0.0727，含 1 次未知用量 |
| 有 Java 经验，验证 Go worker pool | 选择实际编程验收，参考程序通过 WASI 执行；刻意提交没有 worker 的常量输出程序，3 项检查均失败，保留 0 分并转向具体诊断 | 下述同一目录累计 |
| Go 错误作答后的诊断与修复 | 初稿误称关闭 channel 后发送会阻塞，被独立审查拒绝；恢复执行实际修复，纠正为 panic 后发布诊断，原始失败证据保留 | 18 / 0.7783，含 3 次未知用量 |
| 零基础、今天 5 分钟内学完整 Go 后端 | 判断不可行，只提出一个月、每天 30 分钟的具体目标调整；建议处于 pending，用户原目标没有被改写 | 1 / 0.0111，无未知用量 |

Go 场景初次运行暴露了审查契约过度要求、主模型等待计时包含受托工具时间，以及四动作额度无法容纳修复的问题。最终增加明确的课程审查契约，分离模型等待计时，提供批量学习更新，将默认动作额度调整为六，并验证恢复成功。没有隐藏初始失败或删掉失败证据。

## 使用边界

当前交付面向本机单用户，支持多个入口共享课程；尚未提供多人认证或多租户服务。Go 任务运行于 WASI，不提供网络或 cgo；其他操作系统尚需隔离执行适配器。

本次验收证明工程行为及若干教学策略场景。真实学员的理解、次日和一周保留，以及自然使用成本，需要后续实际使用记录；内部 supported 状态、模拟答案和参考程序通过都不能替代学习效果测量。
