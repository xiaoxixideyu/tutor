# Go 切片独立测量题册

观察者每次只提供对应的一组题。各组限 8 分钟，可以手写，不运行代码、不查资料、不使用模型。所有切片均为 `[]int`；写出结果，并简述理由。不会可留空。

## 前测

1. `a := []int{2,4,6}; b := a; b[0] = 8`。此时 `a`、`b` 分别是什么？
2. `a := []int{1,3,5,7}; b := a[1:3]; b[1] = 9`。此时 `a`、`b` 分别是什么？
3. `src := []int{10,20,30}; dst := make([]int,2); n := copy(dst,src)`。`n` 和 `dst` 分别是什么？是否要求两个切片等长？
4. 写出把 `src := []int{3,6}` 复制成独立切片 `dst` 的代码，再写一个修改操作，说明如何检验它们独立。

## 课后测

1. `a := []int{5,7,9}; b := a; a[1] = 2`。此时 `a`、`b` 分别是什么？
2. `a := []int{1,2,3,4}; left := a[:2]; right := a[2:]; left[0] = 8`。此时 `a` 和 `right` 分别是什么？两个切片是否共享底层数组？
3. `src := []int{4,5}; dst := make([]int,0); n := copy(dst,src)`。`n` 和 `dst` 分别是什么？解释原因。
4. 某函数要返回 `src := []int{8,9,10}` 的独立副本。写出实现，再说明修改副本后应检查什么。

## 次日测

1. `a := []int{4,6,8}; b := a[1:]; b[0] = 1`。此时 `a`、`b` 分别是什么？
2. `a := []int{2,4,6}; b := a[:2]; c := a[1:3]; b[1] = 7`。此时 `c` 是什么？指出对应同一元素的两个下标。
3. `src := []int{7,8,9}; dst := make([]int,1); n := copy(dst,src)`。`n` 和 `dst` 分别是什么？
4. `dst := src` 被用于备份 `src := []int{1,5}`。这能否保证之后修改 `dst` 元素不影响 `src`？如不能，改正并给出检验方法。

## 一周测

1. `a := []int{9,8,7}; b := a; b[2] = 0`。此时 `a`、`b` 分别是什么？
2. `a := []int{3,4,5,6}; left := a[:2]; right := a[2:]; right[0] = 1`。此时 `a` 和 `left` 分别是什么？为什么 `left` 的可见元素会或不会改变？
3. `src := []int{2,5}; dst := make([]int,4); n := copy(dst,src)`。`n` 和 `dst` 分别是什么？两个切片不等长是否使调用非法？
4. 修复 `func Clone(src []int) []int { return src }`，使返回的 `[]int` 在元素修改上独立。给出一组验证步骤。
