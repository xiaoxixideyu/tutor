# 2026-10-08 稳定性收尾

本轮处理代码检查中发现的三个业务缺口，保留现有课程文件与学习记录。当前完成工程回归，不等同于完整课程内容验收或真人学习效果验收。

## 行为修正

- **重规划后的补救课**：新增 `plan.scope` 保存课程完整范围。A 曾经已掌握、被待学路径跳过后，即使重新规划，复习失败仍会回到 A；补救通过再回到原路径。旧计划从知识地图恢复范围，看板、课堂及大考后的选课采用同一规则。
- **课后实践**：CLI 的 `practice-gen` 与 `practice` 都支持 `--node`；网页可从每个知识点进入实践，也可在实践页选择知识点。已掌握节点以及全部完成的课程仍可实践。已有课程任务文件不代表所选节点有题，按节点决定生成入口。生成后的执行沿用同一节点，切换时禁止旧流程接收新节点的作答。
- **来源证据**：用 Public Suffix List 按注册域名归组，重复页面、同站子域与同域重定向不算两个来源。节点须有至少两个来源域名且教研返回肯定核对结论，才保留 `verified=true`。重新教研替换本批旧资料，失效链接剔除后重新判定，旧课程读取时也执行同一规则。

来源域名是保守代理，不等于独立出版机构；同机构跨域、转载和事实是否真正受资料支持仍需教研或人工核对。数量门槛不能替代内容质量验收。备课提示已明确区分待验证资料。

- 新增回归覆盖实际 RPC 复习提交 → YAML 存储 → 看板 → 课堂选课；全部掌握后的空待学路径；旧计划恢复；来源门槛和旧文件不被读取改写。

## 日常模型通道

本轮对现有网关做最小请求探测：`claude-opus-4-8` 返回 HTTP 503（约 5.9 秒）；`deepseek-v4.1-flash` 返回 HTTP 200 和 `OK`（约 18.3 秒，报告 35 输入、20 输出 token）。因此将本机 `.env` 的日常模型改为已经有判分基线的 `deepseek-v4.1-flash`，其他接入配置未改。`.env` 不入库。

此次只证明该路由在探测时可用；延迟为单次完整请求耗时，不能视为课堂首字延迟或长期可用性统计。先前的两领域三轮判分记录见 [判分基线](evaluation-2026-10-08.md)，本轮没有重新运行完整模型判分或完整课程。
