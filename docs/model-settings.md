# 网页模型设置

模型渠道可在页面修改。运行 `npm run serve`，打开终端打印的本机地址，点击“模型设置”（默认地址为 `http://127.0.0.1:8788/settings.html`）。即使尚未配置模型和搜索服务，也能启动网页。

## 填写与保存

| 字段 | 填写内容 |
| --- | --- |
| 服务地址 | 渠道的 HTTP/HTTPS 基础地址，通常以 `/v1` 结尾，不包含 `/chat/completions`、查询参数或账号密码 |
| 模型名称 | 渠道支持的完整模型 ID，保留名称中的大小写和路径 |
| API Key | 首次填写渠道密钥；同一服务地址下留空可沿用，填写新值则更换密钥 |
| 推理模式 | 高级设置，默认跟随服务；显式开启／关闭目前仅支持 `deepseek-*` 模型 |
| 上下文长度 | 高级设置，按渠道说明填写；默认 262144，允许 1024–2000000 的整数 |
| 每分钟请求数 | 高级设置，按渠道配额填写；默认 8，允许 1–600 的整数。额度不足时排队等待 |
| 教研回合时限 | 高级设置，单位分钟，允许 1–30，默认 8；限制单个知识点的一次教研回合 |

点击“保存设置”后会显示成功提示和保存时间。刷新或重启后仍保留配置；页面和读取接口只显示密钥是否已配置，不回显密钥，保存后输入框清空。服务地址变更（包括路径变更）时必须重新填写对应密钥，避免把旧渠道密钥发送到新地址。

保存会验证字段并写入本机文件；实际连通性、模型可用性和额度由下一次模型请求验证。课程列表、向导、课堂、大考和实践页面均有设置入口。

## 生效范围与保存位置

配置优先级为：**网页保存文件 > 服务启动环境变量 > 仓库 `.env`**。网页保存不会修改 `.env`。

每个新流程启动时读取最新配置。正在进行的访谈、课堂或考试继续使用开始时的配置；在该会话中发送下一条消息不会切换模型。要使用新配置，应先结束或暂停当前流程，再开始或继续流程。命令行 `npm run agent -- …` 的模型流程同样读取已保存配置；查看课程、复习和执行已有实践任务等零模型操作无需模型配置。

默认保存文件为 `data/model-config.json`，使用原子替换写入，权限为 `0600`（仅当前系统用户可读写）。文件包含密钥，位于已忽略的 `data/` 目录，不提交 Git。运行时模型模板只记录密钥的环境变量名称，不包含密钥值。

多个试学目录默认共用模型配置；需要独立配置时，在启动服务或 CLI 前设置 `TUTOR_MODEL_CONFIG_FILE` 指向单独的文件，建议使用绝对路径。自定义文件也应放在 Git 忽略的目录。若已保存文件损坏，服务会明确报错并停止启动模型流程；修复该文件后再试，不会自动切换到环境中的其他渠道。

联网教研使用的搜索 MCP 地址与令牌仍在环境变量或 `.env` 配置，仅联网教研加载。其他流程无需搜索配置。费用估算仍采用 `config/cost.yaml`，切换渠道或模型后应核对单价。

## 页面一直等待时

“等待模型回复”的秒数是页面等待时间，不能直接视为模型推理耗时。旧后台进程仍在运行、页面却已更新时，可能出现回复已完成但页面无法订阅输出的情况。

`480s 总时限` 是 tutor 设置的 **8 分钟调用预算**，不是模型的思考配额、渠道额度或整门课程的完成时限。一次教研回合可能包含多次模型请求、搜索和正文抓取，它们共享该回合的时限。独立内容审查每个请求另有 240 秒上限；审查与有界修复会使一个知识点的总等待超过 8 分钟。调大教研时限不会加速模型，也不会改变独立审查的时限。

`429` 表示渠道拒绝了超额请求。教学、教研、独立审查及内置重试现在按同一服务地址和密钥共享队列，包括独立 `DSH_HOME` 的 CLI 进程。默认每 61 秒最多 8 次并均匀发起，避免连续审查把一分钟额度瞬间耗完；后台会话标题生成已关闭。收到 429 后共享至少 61 秒冷却，遵守更长的 `Retry-After`；同一请求重试后仍受限便停止整批并保留进度，不继续消耗后续知识点。渠道还可能有其他程序共用额度或额外限制，本机队列不能替其他程序限流。

队列等待计入已有回合时限，取消会立即退出等待，未发起的排队请求不消耗请求预算。新配额在新流程中生效；并行流程使用不同配额时，较低配额在一个窗口内优先。共享状态保存在 `data/model-rate-limits.sqlite`，只含不可逆的渠道标识、请求时间与配额，不含密钥、提示词或回复；可用 `TUTOR_MODEL_RATE_LIMIT_FILE` 指向各进程共用的绝对路径。

教研现在按知识点建立独立会话、逐点审查和保存。每点最多 3 次搜索、2 次抓取、5 次模型请求（含重试与修复），工具只在前 3 次请求可用；每条工具结果最多 6000 字符、合计最多 24000 字符。失败搜索也计入预算，同一失败服务在本点不反复重试。资料太长导致单项审查超时或截断时，生成器可在剩余预算内精简后重审；原失败保留，精简稿仍须完整批准。

课程详情区分“待教研”“已保存 · 待交叉验证”“来源已验证”。默认继续会跳过已保存的完整教研结果，来源不足或尚未相互印证不会冒充已验证；两个不同域名只是数量门槛，不会自动令 `verified=true`。可点击任一知识点的“补查”单独重研。断点绑定课程范围、节点摘要与来源，相关内容修改后重新处理。已保存的节点不会因后续节点失败而丢失，连续两个节点失败后停止本次运行。

页面现在会在启动流程前检查后台协议。如果提示“后台服务与页面版本不兼容”，先结束旧服务，再在当前代码目录运行 `npm run serve` 并刷新页面。设置保存本身无需重启；只有更新后台代码时需要重启旧进程。已保存的课程状态和原始会话日志会保留，未发送的输入不属于已保存作答。
