# tutor 教学 agent 架构

当前版本以单个 TutorAgent 统筹教学。目标、学员原话和学习证据决定策略；程序负责约束、执行、验证、记录与恢复。

~~~mermaid
flowchart LR
  U["用户目标 / 作答 / 反馈"] --> A["TutorAgent 选择行动"]
  S["目标、画像、证据快照"] --> A
  A --> T["受限教学能力工具"]
  T --> V["内容核对 / 判分 / 版本校验"]
  V --> C["原子提交与请求回执"]
  C --> S
  C --> E["结构化事件 / 查询视图"]
  E --> U
~~~

src/domain 定义目标、技能、量规、活动、尝试、证据、假设、能力评定与记忆状态。判分与证据资格是纯规则。独立证据要求由技能量规决定，单条证据需要更强的应用任务；基础题、自述、重复题和提示后答案不能直接证明掌握。

src/application 提供统一 CourseService、CourseRepository、TutorSystem 和 UsageLedger。所有 CLI / HTTP 操作共用同一套提交。请求按 inputHash 去重，expectedRevision 防止过期写入。内容资产先保存，再原子切换状态快照；不同课程使用独立短写锁。课程运行互斥单独保存在 courses/.runs/，覆盖 CLI 与网页的完整处理期间；它不占用状态写锁。启动时只恢复已失去执行者的任务，查询不会暂停其他入口正在进行的教学。

src/agents 负责观察上下文、选择工具、记录简短依据并交回学员。模型可以继续当前活动，也可以换成解释、诊断、迁移任务、修订课程、提出目标变更或结束本次学习。每次作答后重新判断下一步。

src/capabilities 是课程设计、活动核对、盲解、评分、来源抓取、修复与隔离执行服务。候选内容分别核对范围和正确性，代码参考程序先执行测试。没有“集合关系正确就忽略语义否决”的例外。拒绝稿需要实质修改或新依据，不能原样抽样直到通过。

src/runtime 复用 OpenAI 兼容传输、限流、恢复、上下文预算和会话日志，支持通用受限工具注册。默认六步业务动作预算与所有会话共用的请求预算约束循环；多个假设和技能判断可在一步里原子提交。模型等待计时扣除受托工具执行时间，整个教学任务仍受总时限约束。模型对话提供近期背景，长期事实从课程快照及原始证据构造。

src/server 提供本机同源 HTTP/SSE。事件包括活动展示、题目下发、评分、暂停、决策、目标建议和失败；网页不通过终端文案推断业务状态。本进程即时推送事件，并每秒检查课程版本以同步其他入口的提交。状态查询不运行模型，也不扫描历史审查正文。

## 数据与不变量

~~~text
courses/<id>/
  state.json             权威状态、版本、回执、活动和证据索引
  assets/<hash>.json     不可变正文、原始题目、作答和评分
  tasks/<hash>.json      候选内容、审查和失败恢复
  drafts/<hash>.json     可编辑但未计分的输入
data/
  model-config.json      私有连接和推理设置
  model-usage.json       全部模型尝试，含未知用量
  sessions/              模型会话与工具转录
  today.json             可重建的每日推荐缓存
~~~

掌握判断、教学活动完成、记忆调度和目标达成分别表达。一次考试的其他得分不能抵消关键标准失败。目标达成还需独立核对全部目标范围，避免局部计划冒充完整课程。

提示通过明确的工具行动记录。题目指纹不因改题号、改参考答案或交换选项而制造新的独立证据。暂停保留同一活动及题目；重复提交返回原回执，修改已提交答案被拒绝。评分失败时原始答案保持 pending，恢复继续评分。

修改用户目标和承诺以具体建议呈现给用户。已使用的量规不能被无痕覆盖，历史证据与评分依据保持可追溯。对画像的推断以假设保存，验证需要新的真实证据。

代码执行当前支持 macOS Seatbelt 沙箱。Go 通过 WASI 双重约束运行，仅提供标准输入输出及任务工作目录。普通代码不获得课程文件、连接密钥、网络或任意 shell 权限；时间、输出和内存受到限制。

所有生成、审查、评分、重试与日程选择进入用量账。预算依据已报告用量估算，未报告的尝试标为 unknown 并计请求次数。普通页面刷新与既有内容恢复不产生模型请求。

本次实现采用新数据格式；已按用户要求清理历史课程与运行数据，取消旧版兼容与迁移路径。

工程测试与真实模型测试检验程序行为和策略样例。真人学习有效性、长期保留及自然使用成本需要实际使用记录，不能由内部 supported 状态或模拟作答替代。
