# 真实模型判分评测

当前入口检验大考主观题判分：复用正式考试的 `buildExamGradingPrompt`、`config/persona/exam-grade.md`、`AgentChat` 和输出校验器。它不运行完整课程，也不衡量真人是否学会。

## 运行

使用 Node 24 LTS，先安装项目依赖。

```sh
npm run eval:grading                       # 只校验样本，不调用模型
npm run eval:grading -- --live              # 调用 .env 配置的模型，默认重复 3 轮
npm run eval:grading -- --live --repeats 2   # 2–5 轮，限制输出 token 和总运行时间
```

需要对比同一网关中的其他模型时，使用进程环境覆盖，不必修改 `.env`：

```sh
TUTOR_LLM_MODEL=deepseek-v4.1-flash npm run eval:grading -- --live
```

网关 `/models` 公布的名称不保证当前有可用通道；报告中的模型名是请求的路由名称，不能证明网关底层实际模型身份。

## 样本与验收标准

`evals/grading.json` 包含 Go 并发和基础概率统计两个领域，共 12 个样本。覆盖完整正确、同义表述、部分正确、典型误解，以及作答中夹带改分指令。题目按明确列出的四个要点等权评分；预期区间与理由在模型调用前固定。

这是代码助手编写的工程验收集，尚未经过真人盲评，不应称为人工金标准。修改样本或预期区间后，应以新基线重新记录，不能直接与旧结果合并。

- 每个领域、每一轮创建独立会话，避免前一轮判分污染下一轮；轮换题目顺序，减少固定顺序影响。
- 模型只收到题目、参考答案和学员作答；样本标签、预期区间、验收理由不进入提示。
- 每个得分均须落入预定区间；同一样本各轮得分的最大差值须不超过 `maxSpread`（当前 0.15）。单次异常不能被平均值掩盖。
- 遗漏、重复、未知题号、非法分数由正式校验器拒绝，最多进行四轮生成修正。网络异常仍经过正式 `AgentChat` 的重试逻辑。
- 运行错误或缺少轮次均不能算通过。退出码 `0` 表示全部达标，`1` 表示运行失败，`2` 表示评测完成但质量未达标。

同一请求批量判六个样本，与实际考试的单题上下文仍有差异。当前测量不控制供应商的随机种子，使用供应商默认采样配置；三轮只能给出小样本稳定性证据。

## 数据与成本

每次运行写入独立的 `data/evals/grading-<时间>-<随机值>/`：

- `report.json`：样本快照、样本与角色提示的 SHA-256、业务生成请求与回复、校验失败、逐样本分数、波动、会话 ID、耗时和 token。`attempts` 对应业务生成次数；底层请求的重试与截断详见 Harness 会话日志。
- `runner.log`：宿主日志。
- `dsh-home/`：该次评测独立的 Harness 配置与会话日志。
- `workspace/`：空白评测工作目录。

评测不挂载真实课程状态或 MCP，不提供工具调用，不生成会话标题。默认每次输出上限 2048 token，总运行上限 10 分钟；可用 `--max-tokens` 在 256–4096 之间调整。宿主启动失败和中途退出保留失败报告。

费用依照 `config/cost.yaml` 的单价估算，**不是实际账单**。统计包含 Harness 已报告的失败尝试与缓存输入；缓存暂按普通输入单价估算。网络失败等场景可能产生未报告用量。该结果仅覆盖判分，不能外推为访谈、教研、备课、课堂与事实核对的完整成本。

首轮实测及成本修正记录见 [2026-10-08 评测结果](evaluation-2026-10-08.md)。

完整课程验收还需独立测试课程、生成内容核对、真人作答和跨日复测；隔日与一周后的学习保留效果不能通过即时脚本模拟得出。
