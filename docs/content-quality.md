# 教学内容准入

内容必须先通过结构校验，再通过独立审查，才能保存为正式教学材料或向学员展示。适用于知识地图、计划、摸底与复习题库、备课、逐轮讲授、实践任务和大考试卷。真实验证结果见 [本轮记录](content-quality-2026-10-08.md)。

## 检查依据

访谈 runner 把学员输入原文保存为 `profile.requests`，覆盖模型可能自行生成的同名字段。生成器和审查员同时获得原文与目标摘要，明确的原始范围优先。旧档案没有原文时依据 `profile.goal`；未记录的意图无法由系统可靠恢复。规划现在也会读取完整学员档案。

每项内容按当前节点或当前里程碑收窄范围。知识地图、计划、题干、参考答案、`accept`、评分关键词、课中练习、小测、正文、误区、实践 README、提示和测试均纳入相应检查。可选活动也属于课程内容。审查员会获知本项目的边方向约定：`[知识点, 前置知识点]`。

1. 题目先交给新会话盲解。只发送题号、题干和选项，不发送参考答案、关键词、来源摘要、学员档案或预期测试标签。
2. 对“必须、只要、一定、证明”等强断言，程序定位原文分句，由另一新会话专门找反例。明确的格式要求和被引用的错误说法不应被当成事实泛化。
3. 审查员在独立新会话中检查范围和正确性，并对照盲解、反例检查。不能只根据来源摘录或 `verified` 标记批准内容。
4. 选择题的独立答案与参考字母必须一致；可解析的数值答案和审查列出的四则运算由有界有理数解析器精确复算。它不执行模型产生的代码或命令。

每批至多 3 道盲解题、4 条反例检查或 3 个审查单元。每批各用新会话，批准前仍要求全量题号、单元和强断言覆盖齐全。地图先检查骨架，已经发现问题可提前拒绝，不继续审查后续资料；一个节点就是一节实际课堂，不能将额外节点解释成课内要点。重复、遗漏、未知编号、非法结论、无法完成检查以及 `uncertain` 都不能获得准入。程序复算仅覆盖模型列出的算式和可直接解析的数值答案，不能保证提取了所有算式。

生成、讲授、解题和审查角色不会读取或改写本地文件。业务模型默认没有工具；教研仅可搜索和抓取网页。实际文件写入由 runner 在准入后完成，实践执行仍由正式实践 CLI 在学员触发时进行。

## 失败与恢复

JSON 内容最多生成 4 个候选，讲授最多 3 个；语义拒绝意见反馈给生成器，修复后重新完整审查。同一生成过程不会通过重复提交同一个拒绝稿来重新抽取审查结论。审查服务错误或不完整结果会直接停止发布。

失败不会用未通过的候选覆盖原材料，也不会产生成绩或推进掌握度。分批任务中此前已经成功保存的节点会保留。教研修复可能精简原先越界的地图，之后应重新规划；相关内容缓存会随上下文变化失效。

课堂把最后展示且通过审查的回复存入 `lesson.approved_turn`。恢复时，原始日志最后回复必须与该回执一致才可回放；出现被拒的日志尾部、缺少回执或历史会话无法恢复时，从可用的已审查教案及最后批准内容建立新会话。旧日志不会直接展示。`/check` 核对当前准入回执和引用编号；正常缓存命中不会再调用模型，也不会把原资料的重复表述当作新的事实证明。

## 旧课程

```sh
npm run agent -- audit-content <课程名>
```

此命令逐项审查现有地图、计划、题库、教案和实践任务，保存审查证据，不修改学习状态。相同内容已有有效准入时复用记录。退出码 `0` 为全部通过，`1` 为有未完成检查，`2` 为存在内容拒绝。遇到拒绝，可查看记录、修正 YAML 后重审，或运行 `research`、`plan`、`assess`、`learn`、`practice-gen` 重新生成相应材料。

复习 CLI、复习 RPC 和实践 CLI 仍保持零模型调用，但只消费带有效准入的内容。旧文件不会自动视为可信；这些入口在未审查或内容变化时会提示先运行 `audit-content`。`assess` 和 `practice-gen` 会审查已有内容，拒绝时生成替代内容，批准后才替换。

## 证据与缓存

每门课的 `quality/reviews/*.json` 保存候选内容、检查依据、请求和回复、会话、模型、已报告用量、拒绝原因及失败信息。`quality/approved/*.json` 保存可复用准入。它们与其他课程运行数据一样不入 Git。

准入绑定内容、实际使用的学员档案、节点描述、当前范围及审查策略摘要。编辑这些内容会使旧回执失效；单纯考试成绩、复习指针和生成日期变化不属于教学内容变化。回执是本机工作状态，不是抗篡改签名。

Harness 原始日志仍会保存被拒稿。分析教学效果时应以正式输出及准入记录为准；原有 `audit` 对原始日志的忠实度统计尚未按发布回执过滤，不能直接当成学员实际看到的内容。

## 固定样本回归

```sh
npm run eval:content
# 只有 --live 才调用模型；可临时指定通道，不修改 .env
TUTOR_LLM_MODEL=deepseek-v4-pro npm run eval:content -- --live --repeats 2 \
  --cases go-copy-length-bad,go-copy-length-good,go-address-bad,go-address-good
```

`evals/content-regressions.json` 冻结原始错误与正确对照，期望标签和来源说明不进入模型请求。每个样本、每轮使用独立课程目录，不能用上轮缓存冒充重复验证。报告保留全部运行错误、误放行和误拦截；运行错误不算“成功拦截”。原概率末卷要求逐题指出 4 道越界题，不能因只拒绝其中一道就算整份验收通过。

一次评测上限 10 分钟、72 次请求，单次最多 8192 输出 token。长教案、完整地图建议用 `--cases` 单独运行。报告与会话保存在 `data/evals/content-*/`；`--repeats` 支持 1–3，验收建议至少 2 轮。

这套准入仍依赖模型推理，同一模型的不同会话可能共享偏差，不能证明普遍正确或真人学习有效。它增加了延迟和调用成本；超时与不完整结果会影响可用性。范围歧义、误拦截、超时比例和漏判必须继续用冻结样本及真实课程量化，不能只报告已批准样本。
