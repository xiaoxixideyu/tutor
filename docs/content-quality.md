# 教学内容准入

内容必须先通过结构校验，再通过独立审查，才能保存为正式教学材料或向学员展示。适用于知识地图、计划、摸底与复习题库、备课、逐轮讲授、实践任务和大考试卷。真实验证结果见 [本轮记录](content-quality-2026-10-08.md)。

## 检查依据

访谈 runner 把学员输入原文保存为 `profile.requests`，覆盖模型可能自行生成的同名字段。生成器和审查员同时获得原文与目标摘要，明确的原始范围优先。旧档案没有原文时依据 `profile.goal`；未记录的意图无法由系统可靠恢复。规划现在也会读取完整学员档案。

每项内容按当前节点或当前里程碑收窄范围。知识地图、计划、题干、参考答案、`accept`、评分关键词、课中练习、小测、正文、误区、实践 README、提示和测试均纳入相应检查。可选活动也属于课程内容。审查员会获知本项目的边方向约定：`[知识点, 前置知识点]`。

1. 对“必须、只要、一定、证明”等强断言，程序定位原文分句，由新会话专门找反例。明确的格式要求和被引用的错误说法不应被当成事实泛化。已有否定结论时停止安排剩余检查，拒绝该内容。
2. 题目交给另一新会话盲解。只发送题号、题干和选项，不发送参考答案、关键词、来源摘要、学员档案或预期测试标签。
3. 审查员在独立新会话中检查范围和正确性，并对照盲解、反例检查。不能只根据来源摘录或 `verified` 标记批准内容。
4. 选择题的独立答案须对应参考选项。完整选项文字或等价分数只在能唯一映射到某一选项时接受，映射不读取参考答案；多项等价、错误或无法确定的答案仍拦截。可解析的数值答案和审查列出的四则运算由有界有理数解析器精确复算。它不执行模型产生的代码或命令。

每批至多 2 道盲解题、2 条反例检查，或 1 个审查单元（地图、计划至多 2 个）。同一审查最多并发 2 批，每批各用新会话；批准前仍要求全量题号、单元和强断言覆盖齐全。地图先单独检查完整骨架；一个节点就是一节实际课堂，不能将额外节点解释成课内要点。重复、遗漏、未知编号、非法结论、无法完成检查以及 `uncertain` 都不能获得准入。程序复算仅覆盖模型列出的算式和可直接解析的数值答案，不能保证提取了所有算式。

每次审查请求最多 8192 输出 token、240 秒总时长；这两个值由正式入口与内容评测共用。多项批次因截断或超时失败时拆为更小批次，保留原失败记录，完整补查通过后才可批准。单项失败或服务错误不会被当成语义拒绝。认证、权限及模型不存在等永久错误不重试；实测同一可用模型偶发的特定 `404 Route Not Found / bad_response_status_code` 只重试一次，连续失败仍退出。普通业务请求默认总时限 300 秒，教研 480 秒；重试会增加总等待。`TUTOR_LLM_DEADLINE_MS` 可调整未显式指定的业务调用。`TUTOR_LLM_TIMEOUT_MS` 单独控制无输出进展的停滞时间，默认 300 秒。总时限仍会停止持续吐字的请求，并取消底层 agent。

课堂有单轮对话约定：一轮不必覆盖本节全部目标，可以为当前问题简短回顾必要的前置概念；提前教授后续新方法、扩大实验活动或引入排除项仍不可通过。该约定也纳入讲授准入摘要，变化后只使讲授回执的当前复用失效，不抹掉历史发布。

生成、讲授、解题和审查角色不会读取或改写本地文件。业务模型默认没有工具；教研仅可搜索和抓取网页。实际文件写入由 runner 在准入后完成，实践执行仍由正式实践 CLI 在学员触发时进行。

## 失败与恢复

JSON 内容最多生成 4 个候选，讲授最多 3 个；语义拒绝意见反馈给生成器，修复后重新完整审查。同一生成过程不会通过重复提交同一个拒绝稿来重新抽取审查结论。审查服务错误或不完整结果会直接停止发布。

结构合法的生成草稿先保存在 `quality/generation/`；中断后，同一任务可以从待审草稿继续，仍须重新校验结构并取得完整准入。已经明确被拒的草稿保留拒绝意见，恢复后直接修复，不重抽取旧稿结论。首次开课的教案通过后也会保存，即使首段讲授失败，再次开课仍可复用；尚无讲授会话的备课断点没有 `session_id`。

审查中断后可以复用同一内容、策略、角色和逐字相同请求的已完成检查。每个复用结果仍重新解析必需字段，并通过 `reusedFrom` 指向原始证据；缺失或变化的原证据不能支撑准入。原失败不删除，本次只计算新增请求费用。明确拒绝不能通过重新审查同一内容来改成通过；改变内容后重新完整检查。

旧实践任务通过限定路径的文本编辑修复：只能改题干、提示、初始文件内容或测试文本，不能改任务身份、节点、文件路径或任务数量。编辑必须唯一、逐字匹配，每次候选都从原任务应用；修复后的完整任务重新审查，通过后才替换旧文件。

失败不会用未通过的候选覆盖原材料，也不会产生成绩或推进掌握度。分批任务中此前已经成功保存的节点会保留。教研修复可能精简原先越界的地图，之后应重新规划；相关内容缓存会随上下文变化失效。

课堂把最后展示且通过审查的回复存入 `lesson.approved_turn`。恢复时，原始日志最后回复必须与该回执一致才可回放；出现被拒的日志尾部、缺少回执或历史会话无法恢复时，从可用的已审查教案及最后批准内容建立新会话。旧日志不会直接展示。`/check` 核对当前准入回执和引用编号；正常缓存命中不会再调用模型，也不会把原资料的重复表述当作新的事实证明。

## 旧课程

```sh
npm run agent -- audit-content <课程名>
```

此命令逐项审查现有地图、计划、题库、教案和实践任务，保存审查证据，不修改学习状态。相同内容已有有效准入时复用记录。退出码 `0` 为全部通过，`1` 为有未完成检查，`2` 为存在内容拒绝。遇到拒绝，可查看记录、修正 YAML 后重审，或运行 `research`、`plan`、`assess`、`learn`、`practice-gen` 重新生成相应材料。

复习 CLI、复习 RPC 和实践 CLI 仍保持零模型调用，但只消费带有效准入的内容。旧文件不会自动视为可信；这些入口在未审查或内容变化时会提示先运行 `audit-content`。`assess` 和 `practice-gen` 会审查已有内容，拒绝时生成替代内容，批准后才替换。

## 证据与缓存

每门课的 `quality/reviews/*.json` 保存候选内容、检查依据、请求和回复、会话、模型、已报告用量、耗时、拒绝原因及失败信息。`quality/approved/*.json` 保存可复用准入。它们与其他课程运行数据一样不入 Git。

准入绑定内容、实际使用的学员档案、节点描述、当前范围及审查策略摘要。编辑这些内容会使旧回执失效；单纯考试成绩、复习指针和生成日期变化不属于教学内容变化。回执是本机工作状态，不是抗篡改签名。

Harness 原始日志仍会保存被拒稿。正式讲授写入输出成功后，`quality/published/` 记录会话 id、事件序号、完整文本及对应准入；恢复时重放同一事件不重复计数。`audit` 默认只统计与发布回执精确匹配的讲授，仍计入全部请求成本。无回执时覆盖率为 `null`，不推断内容已发布；`--raw` 仅供排查，明确标记原始日志不代表正式讲授。回执证明 runner 已输出，不证明学员已经阅读或理解。

实践状态绑定任务内容摘要，任务修改后重新验收。未被学员修改的初始文件可自动更新；已有作答保留，新模板另存于 `.tutor-materials/` 并提示位置。执行器限制输出、终止超时进程组，并过滤服务凭据环境变量，但仍不是操作系统沙箱，程序保有当前用户的文件与网络权限。

## 固定样本回归

```sh
npm run eval:content
# 整套逐例执行，每例独立限时；只有 --live 才调用模型
npm run eval:content:all -- --live
# 单独检查一个样本
npm run eval:content -- --live --repeats 2 --cases go-copy-length-good
# 仅补验指定案例，原文件与期望标签不变；失败记录仍保留
npm run eval:content:all -- --live --cases probability-sum-good,probability-complement-good
# 新编迁移样本单独保留，不能混称原始冻结样本
npm run eval:content:all -- --live --repeats 1 --fixtures evals/content-heldout-2026-10-08.json
# 单轮讲解及下一课边界的新增回归对照（不是留出集）
npm run eval:content:all -- --live --fixtures evals/content-turn-regressions.json
```

`evals/content-regressions.json` 冻结原始错误与正确对照，期望标签和来源说明不进入模型请求。每个样本、每轮使用独立课程目录，不能用上轮缓存冒充重复验证。报告保留全部运行错误、误放行和误拦截；运行错误不算“成功拦截”。原概率末卷要求逐题指出 4 道越界题，不能因只拒绝其中一道就算整份验收通过。

单个评测进程上限 10 分钟、72 次请求，单次最多 8192 输出 token。`eval:content:all` 为每例启动独立进程，并保存整套汇总，避免整套共用十分钟导致后半段未运行。报告与会话保存在 `data/evals/content-*/`，汇总在 `data/evals/content-suite-*/`；`--repeats` 支持 1–3，验收建议至少 2 轮。超时仍计为未完成，不能从分母删除。

`TUTOR_LLM_THINKING=on|off` 可为 DeepSeek 接口显式设置推理模式；未设置时保留供应商默认行为。关闭推理的对照已出现误拦截，不能作为已验证的试学提速设置。网关公布模型名称不等于路由可用，临时模型对比及费用必须另行记录，不修改个人 `.env`。

这套准入仍依赖模型推理，同一模型的不同会话可能共享偏差，不能证明普遍正确或真人学习有效。它增加了延迟和调用成本；超时与不完整结果会影响可用性。范围歧义、误拦截、超时比例和漏判必须继续用冻结样本及真实课程量化，不能只报告已批准样本。
